# 讲座报名助手（公开版）

供 Edge 和 Chrome 使用的本地扩展，适用于腾讯文档中包含「姓名」「学号」「年级」和一条须知的四题讲座报名表。每个人都可以填写自己的年级。

## 安装

1. 下载并解压最新公开版，保留解压后的文件夹。[下载扩展 ZIP](https://github.com/wangzifan396-wzf/lecture-signup-public/releases/latest/download/lecture-signup-public.zip)
2. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`，开启「开发人员模式」。
3. 点「加载解压缩的扩展」，选择含有 `manifest.json` 的文件夹。安装后刷新已打开的表单标签页。如果也装过个人版，请只启用本次要使用的版本，再刷新表单。

## 首次填写

1. 提前登录腾讯文档，在装有扩展的浏览器中打开主办方的**填写链接**，点右下角「报名助手 · 公开版」。
2. 输入姓名、学号和年级。年级请照本场选项完整填写。例如选项写「2025级博士」，就输入 `2025级博士`。只输入年份无法匹配完整选项。检查时若找不到年级，面板会列出识别到的选项，可复制后修改。
3. 「开放后第几秒点提交」默认为 4，支持 3.1 至 300 秒，可保留一位小数。点「保存本机资料」，下次打开表单会带出姓名、学号、年级和提交秒数。换场次可以临时修改，再点保存才会更新下次的默认值。「清除本机资料」会清空个人字段，把提交秒数恢复为 4。
4. 核对本场须知，将面板里的须知题干改成表上的完整文字，确认答项是「我已知晓」。可先点「检查本页（不填写）」查看匹配结果。

## 启动本场

- **全自动**是默认模式。填写本场开放日期和时间，点「启动本场」。例如开放时间为 19:20:00、提交秒数为 4，助手从 19:20:00 开始等待题目可填，目标在 19:20:04 点一次提交。如果页面到 19:20:08 才能填写，填好核对后就提交。弹出「确认提交你的结果吗？」时点一次确认，看到页面回执后才提示提交结果。实际时间会受页面、浏览器和网络影响。
- **仅填写，由我提交**会填好姓名、学号，选择年级和「我已知晓」。完成后由使用者检查并提交。
- 开放时间使用电脑本地时间，每场单独设置，留空会从点「启动本场」时开始计时。运行时可切换标签，保留报名页并避免电脑休眠；需要停止时点「取消本次任务」。

## 离线演练与资料

直接在浏览器里打开同目录的 `demo.html`，可以用虚构资料试跑。试着把面板里的年级从「2025级硕士」改成「2026级博士」，选「仅填写，由我提交」，就能在表单上分别核对年级和须知。

保存的资料在当前浏览器的扩展本地存储中。扩展通过表单的可见控件填写，提交的答案由腾讯文档按该表单的设置收集。分发时分享本项目文件夹或压缩包即可。
